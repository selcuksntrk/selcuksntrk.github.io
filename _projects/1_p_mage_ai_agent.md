A GPT-4o-mini powered project planning AI agent that helps organize, plan, and manage projects efficiently.

## Overview

P-Mage is an intelligent project management assistant built with modern AI capabilities. It uses GPT-4o-mini to understand project requirements and provide actionable planning guidance.

## Features

- **Smart Project Planning** - AI-powered project breakdown and task organization
- **Efficient Management** - Streamlined workflow recommendations
- **Natural Language Interface** - Communicate with the agent naturally
